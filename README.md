# Portable USB-MIDI-CV Converter

Ultraportable device for converting MIDI between various hardware standard

Allows you to convert signal between MIDI USB Device, MIDI USB host, MIDI TRS and CV.




## Features
* 1x1 MIDI TRS interface
* Tiny footprint (3cm x 3cm x 1cm)
* USB-C powered
* MIDI USB-MIDI compliant Device
* Plug and play - no drivers needed
* Can act USB host for USB MIDI keyboards, synths....
* Optoisolated TRS MIDI input
* Buffered TRS MIDI output
* CV (0-5 V)
* Powered by RP2040
